Validation Guide

Step 1: Start your Node.js API server (`npm start` or `npm run dev`).

Step 2: Obtain a valid JWT token by logging in via POST `/api/auth/login` (or using the Swagger UI at `/api-docs`).

Step 3: Paste the token into the JWT input on the left and click Connect.

Step 4: Trigger a task update (create, update status, re-assign, or delete) using Swagger UI, Postman, or `npm run test`.

Note: The socket listener authenticates tokens using the JWT secret. Connecting joins you to your user-specific room (`user_id`) and team room (`team_id`) automatically.
